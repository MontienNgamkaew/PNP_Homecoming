# บัญชีผู้ดูแลและประวัติผู้ดำเนินการ

ระบบ PHP บน pnp2.montien.tech ใช้บัญชีผู้ดูแลแยกคน

- บัญชีเริ่มต้นคือ `admin` สิทธิ์ **ผู้ดูแลสูงสุด** ใช้ password hash เดิมจาก private config โดยไม่เปลี่ยนรหัสผ่านเดิม
- เมื่อมีบัญชีใน `admin_users` แล้ว การเข้าสู่ระบบตรวจจากบัญชีนี้เท่านั้น ไม่ใช้รหัสเดิมใน config เป็นทางเข้าสำรอง
- ผู้ดูแลสูงสุดเพิ่มบัญชี กำหนดสิทธิ์ เปลี่ยนชื่อแสดง เปิด/ปิดบัญชี และตั้งรหัสผ่านใหม่ให้ผู้อื่นได้ การตั้งรหัสผ่านใหม่ต้องยืนยันรหัสผ่านของผู้ดูแลสูงสุดที่กำลังใช้งาน
- ผู้ดูแลทุกคนเปลี่ยนรหัสผ่านตนเองได้ โดยกรอกรหัสปัจจุบันและรหัสใหม่อย่างน้อย 8 ตัวอักษร (ไม่เกิน 72 ไบต์)
- เปลี่ยน/รีเซ็ตรหัสผ่าน ปิดบัญชี หรือเปลี่ยนสิทธิ์ จะยกเลิกเซสชันของบัญชีนั้น การเปลี่ยนชื่อแสดงอย่างเดียวไม่ยกเลิกเซสชัน
- ไม่ลบบัญชีถาวร ใช้ปิดใช้งานเพื่อเก็บประวัติ และไม่ให้ปิดบัญชีหรือลดสิทธิ์ผู้ดูแลสูงสุดที่กำลังใช้งาน ต้องมีผู้ดูแลสูงสุดที่ใช้งานได้อย่างน้อยหนึ่งบัญชี

## สิทธิ์

ผู้ดูแลสูงสุด: จัดการผู้ใช้ สิทธิ์ ข้อมูลบัญชีรับชำระ QR ราคา และข้อความแบนเนอร์ พร้อมดูประวัติรวมทั้งหมด

ผู้ดูแล: จัดการรายการรับบริจาค การจอง รับเงินสด ยืนยันยอด ตั๋ว รายงาน CSV ข้อมูลภาษี คำอวยพร และโปสเตอร์ พร้อมดูประวัติรายรายการ

สิทธิ์ตรวจที่ API ฝั่งเซิร์ฟเวอร์ ไม่ได้อาศัยการซ่อนปุ่มอย่างเดียว

## ประวัติ

`admin_activity` บันทึกบัญชี ชื่อแสดง ณ เวลานั้น วันเวลา การดำเนินการ และรายการเป้าหมาย โดยได้ตัวผู้ดำเนินการจากเซสชันที่ตรวจแล้ว ไม่รับชื่อผู้ดำเนินการจากแบบฟอร์ม

การเปลี่ยนข้อมูลและการลงประวัติอยู่ใน transaction เดียวกัน การทำรายการที่ไม่สำเร็จจะไม่บันทึกเป็นความสำเร็จ ไม่เก็บรหัสผ่าน token หรือสำเนาข้อมูลภาษี/สลิปในประวัติรวม การดูตั๋ว สลิป และส่งออก CSV สำหรับผู้ดูแลบันทึกเป็นกิจกรรมด้วย

รายการเงินสดใหม่แสดงผู้บันทึก ส่วนเงินโอนแสดงผู้แจ้งรายการและผู้ดูแลที่จัดการล่าสุด มีปุ่มประวัติรายรายการ บัญชีที่เปลี่ยนชื่อภายหลังไม่เปลี่ยนชื่อในประวัติเดิม

ข้อมูลก่อนเปิดระบบบัญชีแยกคนยังเก็บในตารางประวัติเดิม ไม่ใส่ชื่อย้อนหลังที่ระบบไม่เคยบันทึกไว้

## ย้ายระบบและสำรอง

สำรองฐานข้อมูลก่อนเรียก `php portal-private/migrate-admins.php` ผ่าน CLI สคริปต์สร้างเฉพาะตารางใหม่และบัญชีเริ่มต้น ไม่แก้รายการเงินหรือการจอง เซสชันผู้ดูแลรุ่นเก่าจะใช้ไม่ได้หลังเผยแพร่ ต้องเข้าสู่ระบบใหม่ด้วยชื่อ `admin` และรหัสเดิม

สำรอง JSON รุ่นปัจจุบันรวม `admin_users` และ `admin_activity` รวม 14 ตาราง ไม่รวมเซสชัน หากกู้คืนจากสำรองเก่าที่ไม่มีบัญชีแยกคน ต้องตรวจและตั้งบัญชีผู้ดูแลก่อนเปิดใช้งาน เพราะระบบจะสร้างบัญชีเริ่มต้นจาก private config เมื่อยังไม่มีบัญชีใดเลย
