## การนำไปใช้
เปิด ../../design-gallery.html ผ่านเซิร์ฟเวอร์ตัวอย่างเพื่อดูและดาวน์โหลดรายไฟล์
ขนาดรูปเป็นขนาดพิกเซลจริง ใช้ CSS ปรับตามหน้าจอ
บนมือถือเลือก hero-mobile.png โดยใช้ picture/media query เพื่อไม่ตัดส่วนตกแต่งผิดตำแหน่ง
พื้นหลังใช้ background-size: cover และไม่ควรทำซ้ำเป็นลายต่อเนื่อง
ภาพที่มีข้อความให้กำหนด alt หรือ aria-label ชื่อตามหน้าที่ของปุ่ม
สีสถานะโต๊ะต้องใช้คู่กับข้อความสถานะเสมอ
ภาพไม่มี QR บัญชีหรือราคาฝังไว้ จึงเปลี่ยนราคาและข้อมูลในระบบได้

## วิธีสร้าง
พื้นหลังและแบนเนอร์ 3 ภาพ: built-in ImageGen; prompt จริงอยู่ในไฟล์ *-prompt.txt
ปุ่มและไอคอน: วาดรูปทรงและตัวอักษรด้วย AppKit จาก make-ui-assets.swift เพื่อให้ข้อความไทยตรงและพื้นโปร่งใส
ภาพ AI เป็นลวดลายตกแต่งใหม่ ไม่ใช่ภาพสถานที่จริง และไม่ได้แก้ไขโลโก้หรือภาพเสื้อต้นฉบับ
ยังไม่ได้แทนที่ภาพหรือโค้ดของเว็บไซต์เดิม
